# SubOff (섭오프)

구독 서비스와 결제 일정을 통합 관리하고, 이용 기록을 바탕으로 불필요한 구독을 점검하여 고정 지출 절감을 돕는 Android 앱입니다.


## 개발 목적

여러 구독의 결제일과 요금을 한곳에서 확인하고, 무료 체험 종료 시점을 놓치지 않도록 돕습니다. 사용자가 직접 기록한 최근 이용 빈도를 기준으로 구독 유지 여부를 검토할 수 있도록 합니다.

주요 대상은 여러 구독을 이용하는 대학생과 사회초년생, 무료 체험 종료일이나 자동 결제일을 놓친 경험이 있는 사용자입니다.

## 주요 기능

| 기능 | 계획 |
| --- | --- |
| 구독 등록 및 관리 | 서비스명, 카테고리, 요금, 결제 주기·기준일, 무료 체험 정보를 등록·수정하고 해지 상태로 변경 |
| 결제 일정 관리 | 다음 결제 예정일과 무료 체험 종료일, 종료 임박 서비스 표시 |
| 이용 현황 점검 | 최근 30일 이용 빈도를 기록하고 이용 빈도가 낮은 구독에 점검 권장 안내 |
| 지출 분석 | 월평균 구독료, 연간 환산 금액, 카테고리별 비중과 예상 절약액 확인 |
| 목록 및 상세 조회 | 활성·해지 상태 필터, 결제 예정일·금액 정렬, 구독 상세 조회 |

해지 처리는 앱 내부의 관리 상태를 변경하는 기능입니다. 실제 서비스의 구독을 자동으로 해지하지 않습니다.

## 기술 계획

- Kotlin, Android Studio
- Fragment 및 XML 레이아웃
- Navigation Component
- RecyclerView
- Room (Entity, DAO, Database), Repository
- Kotlin 날짜 계산 및 금액 계산 로직

## 화면 구성

1. 홈: 활성 구독 수, 월평균 구독료, 결제 일정 및 무료 체험 종료 임박 정보
2. 구독 목록: 상태 필터, 정렬, RecyclerView, 신규 등록
3. 구독 등록·수정: 구독 정보 입력 및 날짜 선택
4. 구독 상세·점검: 이용 빈도 기록, 점검 안내, 수정 및 해지 처리
5. 지출 분석: 월·연간 환산 금액, 카테고리별 지출, 점검 대상 및 예상 절약액
